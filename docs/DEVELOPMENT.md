# בית ויליאמס - סביבת פיתוח חדשה

הריפו המקורי מכיל קובץ פריסה בנוי (`bundle.js`) ולא קבצי מקור.
כדי לא לשבור את מה שרץ ברנדר, השלב הראשון הוא ליצור מקור חדש תחת `src/`.

## מה יש כרגע

- `index.html` ו-`bundle.js`: הגרסה הישנה שרצה בפרודקשן.
- `src/`: התחלה של גרסת מקור חדשה ונקייה.
- `src/api.js`: שכבת תקשורת מול Google Apps Script.
- `src/config.js`: כתובת API ושמות טבלאות.
- `_backup_original/`: גיבוי מקומי של הקבצים כפי שנמשכו מגיט. לא מעלים אותו.

## איך לעבוד

1. משאירים את `bundle.js` כמו שהוא עד שמסך חדש מוכן.
2. מעבירים מסך אחד בכל פעם מתוך האפליקציה הישנה אל `src/components`.
3. בודקים מול אותו Apps Script קיים.
4. רק אחרי שהגרסה החדשה מוכנה, מחליפים את הפריסה ברנדר לבילד של Vite.

## פקודות

```bash
npm install
npm run dev
npm run build
```

בפיתוח פותחים את:

```text
http://localhost:5173/src-index.html
```

`index.html` נשאר הגרסה הישנה שרצה היום, כדי לא לשבור את רנדר בטעות.

## כלל בטיחות

לא עורכים ישירות את `bundle.js` אלא אם אין ברירה.
כל שינוי גדול צריך להיות בקבצי מקור תחת `src/`.
